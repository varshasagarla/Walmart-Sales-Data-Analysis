# Walmart-Sales-Data-Analysis

## Project Overview

Walmart Sales Data Analysis is a data analytics project focused on analyzing retail sales data to understand sales performance, customer purchasing patterns, product performance, and business trends.

The project involves exploring and analyzing Walmart sales data to identify meaningful patterns and generate useful business insights. By using data analysis techniques and visualization tools, this project helps understand how different factors such as product categories, customer types, payment methods, and time periods influence sales performance.

## Objectives

- Analyze Walmart sales data to understand overall business performance.
- Identify top-performing product categories based on sales.
- Understand customer purchasing behavior and preferences.
- Analyze sales trends across different days and time periods.
- Compare sales performance across different branches and cities.
- Identify popular payment methods used by customers.
- Generate meaningful insights to support better business decisions.

## Tools and Technologies Used

- **Python:** Used for data analysis and processing.
- **Pandas:** Used for data cleaning, manipulation, and analysis.
- **NumPy:** Used for numerical calculations and statistical operations.
- **Matplotlib:** Used to create charts and visualize sales trends.
- **Seaborn:** Used to create statistical visualizations.
- **Jupyter Notebook / Google Colab:** Used to write and execute Python code.

## Dataset Description

The project uses Walmart sales transaction data containing information about customer purchases, product categories, sales amounts, and transaction details.

The dataset includes columns such as:

| Column Name | Description |
|---|---|
| Invoice ID | Unique transaction identification number |
| Branch | Branch where the purchase was made |
| City | City of the Walmart branch |
| Customer Type | Type of customer (Member or Normal) |
| Gender | Customer gender |
| Product Line | Category of products purchased |
| Unit Price | Price of one product unit |
| Quantity | Number of products purchased |
| Tax | Tax amount applied to the transaction |
| Total | Total amount paid by the customer |
| Date | Date of the transaction |
| Time | Time of the transaction |
| Payment | Payment method used |
| COGS | Cost of Goods Sold |
| Gross Income | Income generated from the transaction |
| Rating | Customer rating for the purchase |
